# Hosting Plan

Use this site as a static booking page. Static means there is no server code to maintain.

## Best Cheap Setup

- Hosting: GitHub Pages for the public website
- Domain: buy one domain through Cloudflare Registrar or another registrar
- Form: FormSubmit emails submissions to `Lachlansnow798@gmail.com`

## Important

`localhost` only means your laptop. It is useful for previewing the site, but it is not a public website and it will stop when your laptop/server stops. For a public site that stays online, deploy the files to a hosting provider.

## Deployment Steps

1. Create a public GitHub repository named `nearby-page-co`.
2. Push this folder to the repository.
3. Turn on GitHub Pages from the `main` branch and `/root` folder.
4. Wait for the GitHub Pages URL to publish.
5. Buy a domain only after the GitHub Pages URL works.
6. Point the domain DNS to GitHub Pages.
7. Submit one test form and click the FormSubmit activation email if it arrives.

## First Domain Ideas

- nearbypage.co
- nearbypage.com
- nearbypageco.com
- simplelocalpages.com

Pick a name that sounds boring and trustworthy. Clever names matter less than getting replies. Avoid `.com.au` until you have an adult helping with ABN or business eligibility.
